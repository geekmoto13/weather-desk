WEATHER DESK US - BUILD 30

UPDATING: close the old console and keep the old folder as a backup.
Extract this ZIP into a new folder. Copy your matching edition's
private folder into the new app folder to keep settings and history.

Bundled Python: double-click START-WEATHER-DESK.bat
Installed Python 3.10+: double-click START-WITH-INSTALLED-PYTHON.bat
Your browser opens http://127.0.0.1:8765/ . Keep the console open.

For startup details run CHECK-WEATHER-DESK-RUNTIME.bat.
The bundled option uses only the included runtime; it never silently
switches Python. This version fixes isolated Python's app import path.

See README.md for setup, data sources and saved-data information.

Public weather now requires a station reporting measured rainfall as well as
a recent temperature. Missing rain data never qualifies as a dry zero.

The forecast beacon now includes the Berkeley Building rhyme.
The highlighted line matches the current forecast signal.

FREE SATELLITE LIGHTNING
NOAA GOES lightning is automatic in the US edition. No account or API key is needed. GOES-East or GOES-West is selected for your location.
The nearby-flash panel shows distance, direction and occurrence time.
It loads a 45-minute observation window through the displayed satellite time.
A provisional reading is the nearest flash loaded so far, while earlier
files are still loading. Missing/old data never mean no lightning.
Blitzortung remains a separate free live map. No Weatherbit subscription is
used or required. Keep the private folder to retain keys, settings and caches.

PUBLIC STATION SEARCH AND PRESSURE HISTORY
Optional Weather Underground data API key: Settings > More nearby personal stations.
CWOP remains available without a key. Your connected Ambient station keeps priority.
Earlier pressure is now recalled from the selected station where available,
then saved locally. Keep the private folder when updating.

NEW IN THIS BUILD
Sun & Moon shows the current twilight stage.
The rainfall heading shows days since recorded rain (hover for source/time).
Beaufort uses a ten-minute mean; sparse wind data remains unavailable.
Keep this edition's private folder when updating to retain rain history.

NETWORK ACCESS (optional): double-click START-WEATHER-DESK-LAN.bat instead.
The console lists addresses like http://192.168.1.50:8765/ to open from other
devices on your home network. There is no password, so use it only on a network
you trust. Allow Python through Windows Firewall on Private networks only.
